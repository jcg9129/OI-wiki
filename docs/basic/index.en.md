An **algorithm**, as the name suggests, is a method of computation. Algorithms are usually used to solve specific computational tasks, but unlike a program that can run directly on a computer, an algorithm uses a mathematical description and focuses more on the idea; it can be regarded as an abstract program. The same algorithm can have many different implementations, and two different programs may use the same algorithm.

This chapter introduces some fundamental algorithms. When a computational task is general enough to appear widely across various problems, the algorithm solving that task gets called by more algorithms, making it quite important and fundamental. At the same time, the more general an algorithm is, the more concise it usually is, and the closer it is to an idea rather than a program. The algorithms introduced in this chapter are elegant and interesting enough, and they will also appear frequently in the advanced content that follows.

## About This Project

**OI Wiki** strives to be a free, open, and continuously updated knowledge hub for **competitive programming**.

## How to Get in Touch

This project mainly uses [Issues](https://github.com/OI-wiki/OI-wiki/issues)/[QQ](https://jq.qq.com/?_wv=1027&k=5EfkM6K)/[Telegram](https://t.me/OI_wiki) for communication.

The Telegram group link is [@OI\_wiki](https://t.me/OI_wiki), and the QQ group number is [588793226](https://jq.qq.com/?_wv=1027&k=5EfkM6K). You are welcome to join.

???+ note "Note"
    In principle, the groups above are **OI Wiki discussion groups**, so please try not to post too much content unrelated to **OI Wiki** in them.

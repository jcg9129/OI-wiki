This chapter introduces the mathematical knowledge that may be used in OI. Computer science is closely related to mathematics, and competitive programming especially emphasizes discrete, concrete mathematics represented by number theory, permutations and combinations, probability and expectation, and polynomials: it focuses on program implementation and real-world problems, and can appear in problems of almost any category.

In fact, the algorithms, data structures, automata, etc. involved in competitive programming can also be considered to belong to the realm of mathematics, but this content is subdivided into specific chapters such as strings and given an application background for better understanding. This chapter mainly introduces knowledge such as some basic concepts in mathematics, algebra, number theory, game theory, and probability theory. Using this knowledge can help optimize other algorithms and data structures, for example:

-   Using polynomials to optimize convolution-form knapsacks, to solve some string problems.
-   The background of many recurrence-type problems is permutations and combinations or probability and expectation, which can be further derived and solved using generating functions, and the algorithmic efficiency can be optimized using FFT-based divide-and-conquer.
-   Using congruences and rings to analyze the possible weight sums, under a modulus, of non-simple paths on a graph, and maintaining them with a weighted disjoint-set union.

In addition, high-school mathematics is the foundation of the mathematics for informatics competitions; mastering the basic concepts and properties in the textbooks can better help in learning the content of this chapter.

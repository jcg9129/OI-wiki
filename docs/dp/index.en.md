This chapter introduces dynamic programming (DP), the problems it solves, and the algorithms and optimizations designed based on it.

Dynamic programming is a method for solving complex problems by decomposing the original problem into relatively simple subproblems.

Since dynamic programming is not a specific algorithm but a method for solving particular problems, it appears in all kinds of data structures, and the types of problems related to it are also more varied.

In OI, recursive solutions to non-optimization problems such as counting are also often loosely called DP, so this chapter lists them together. In fact, dynamic programming does have many similarities with other types of recurrences; when studying, you can pay attention to the similarities and differences between them.

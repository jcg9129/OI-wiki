## Vertex coloring

(discussed for undirected graphs without self-loops)

Color the vertices of an undirected graph, and adjacent vertices cannot have the same color. If G is $k$-colorable but not $(k-1)$-colorable, then k is called the chromatic number of G, denoted $\chi(G)$.

For any graph G, $\chi(G) \leq \Delta(G) + 1$, where $\Delta(G)$ is the maximum degree.

### Brooks' theorem

If a connected graph is neither a complete graph nor an odd cycle, then $\chi(G) \leq \Delta(G)$.

#### Proof

???+ note "Proof"
    Let $|V(G)|=n$; consider mathematical induction.
    
    First, when $n\leq 3$, the proposition obviously holds.
    
    Next, assume the proposition holds for $n-1$; below we will strengthen the proposition step by step.
    
    We may as well only consider $\Delta(G)$-regular graphs, because for non-regular graphs, they can be seen as constructed by deleting some edges from a regular graph, and this process does not affect the conclusion.
    
    For any regular graph G that is neither a complete graph nor an odd cycle, take any point v in it, and consider the subgraph $H:=G-v$; by the induction hypothesis, $\chi(H)\leq\Delta(H)=\Delta(G)$; next we only need to prove that inserting v into H does not affect the conclusion.
    
    Let $\Delta:=\Delta(G)$; suppose the $\Delta$ colors H is colored with are $c_1,c_2,\dots,c_{\Delta}$ respectively, and the $\Delta$ adjacent points of v are $v_1,v_1,\dots,v_{\Delta}$. We may as well assume the colors of these adjacent points of v are pairwise distinct, otherwise the proposition is proved.
    
    Next we let all points colored $c_i$ or $c_j$ in H and all edges between them form a subgraph $H_{i,j}$. We may as well assume any 2 distinct points $v_i$, $v_j$ must be in the same connected component of $H_{i,j}$, otherwise if in two connected components, we can swap the colors of all points in one connected component, so that $v_i$, $v_j$ have the same color.
    
    > Swapping colors here means that if the graph has only two colors a, b, then color all points originally colored a in the graph with color b, and color all points originally colored b in the graph with color a.
    
    We let the above connected component be $C_{i,j}$; then $C_{i,j}$ must only be a path from $v_i$ to $v_j$. Because the degree of $v_i$ in H is $\Delta-1$, the colors of $v_i$'s adjacent points in H must be pairwise distinct, otherwise we can color $v_i$ another color, thereby repeating a color with v's other adjacent points, so the number of $v_i$'s adjacent points in $C_{i,j}$ is 1, and $v_j$ likewise. Then we take a path from $v_i$ to $v_j$ in $C_{i,j}$, let it be P; if $C_{i,j}\ne P$, then we color the points on the path P in order along P, and let the first point with degree greater than 2 encountered be u; note that u's adjacent points use at most $\Delta-2$ colors, so u can be recolored, thereby making $v_i$, $v_j$ disconnected.
    
    Then it is not hard to find that for any 3 distinct points $v_i$, $v_j$, $v_k$, $V(C_{i,j})\cap V(C_{j,k})=\{v_j\}$.
    
    Here our work of strengthening the proposition is done.
    
    Next is very simple. First, if v's adjacent points are pairwise adjacent, then the proposition is proved. We may as well assume $v_1$, $v_2$ are not adjacent; take an adjacent point w of $v_1$ in $C_{1,2}$, and swap the colors in $C_{1,3}$. In the new graph obtained, $w\in V(C_{1,2})\cap V(C_{2,3})$, a contradiction.
    
    At this point the proof of the proposition is complete.

### Welsh–Powell algorithm

The Welsh–Powell algorithm is a greedy algorithm for finding a coloring scheme when **the maximum number of colors is not restricted**.

For an undirected graph G without self-loops, let $V(G):=\{v_1,v_2,\dots,v_n\}$ satisfy.

$\deg(v_i)\geq\deg(v_{i+1}),~\forall 1\leq i\leq n-1$

After coloring by the Welsh–Powell algorithm, the number of colors is at most $\max_{i=1}^n\min\{\deg(v_i)+1,i\}$; the time complexity of this algorithm is $O\left(n\max_{i=1}^n\min\{\deg(v_i)+1,i\}\right)=O(n^2)$.

#### Process

1.  Arrange the currently-uncolored points in descending order of degree.
2.  Color the first point with an unused color.
3.  Traverse the next points in order; if the current point is **not adjacent** to all points with the **same** color as the first point, then color this point with the same color as the first point.
4.  If there are still uncolored points, go back to step 1, otherwise end.

#### Proof

???+ note "Proof"
    For an undirected graph G without self-loops, let $V(G):=\{v_1,v_2,\dots,v_n\}$ satisfy
    
    $\deg(v_i)\geq\deg(v_{i+1}),~\forall 1\leq i\leq n-1$
    
    Let $V_0=\varnothing$; we take a subset $V_m$ of $V(G)\setminus\bigcup_{i=0}^{m-1} V_i$, whose elements satisfy
    
    1.  $v_{k_m}\in V_m$, where $k_m=\min\{k:v_k\notin\bigcup_{i=0}^{m-1} V_i\}$
    2.  If
    
        $\{v_{i_{m,1}},v_{i_{m,2}},\dots,v_{i_{m,l_m}}\}\subset V_m,~i_{m,1}<i_{m,2}<\dots<i_{m,l_m}$
    
        then $v_j\in V_m$ if and only if
    
        1.  $j>i_{m,l_m}$
        2.  $v_j$ is not adjacent to any of $v_{i_{m,1}},v_{i_{m,2}},\dots,v_{i_{m,l_m}}$
    
    Obviously if the points in $V_i$ are colored the $i$-th color, then this coloring scheme is the scheme given by the Welsh–Powell algorithm; obviously we have
    
    -   $V_1\neq\varnothing$
    -   $V_i\cap V_j=\varnothing\iff i\neq j$
    -   $\exists \alpha(G)\in\Bbb{N}^*,\forall i>\alpha(G),~s.t.~ V_i=\varnothing$
    
    We only need to prove:
    
    $\bigcup_{i=1}^{\alpha(G)} V_i=V(G)$
    
    where
    
    $\chi(G)\leq\alpha(G)\leq\max_{i=1}^n\min\{\deg(v_i)+1,i\}$
    
    The inequality on the left of the above expression obviously holds; we consider the right.
    
    First it is not hard to obtain:
    
    If $v\notin\bigcup_{i=1}^mV_i$, then v is adjacent to at least one point in each of $V_1,V_2,\dots,V_m$, so $\deg(v)\geq m$
    
    Further
    
    $v_j\in\bigcup_{i=1}^{\deg(v_j)+1}V_i$
    
    On the other hand, based on the construction method of the sequence $\{V_i\}$, it is not hard to find
    
    $v_j\in\bigcup_{i=1}^j V_i$
    
    Combining the two expressions gives the proof.

## Edge coloring

For edge coloring of an undirected graph, adjacent edges are required to be colored with different colors. If G is k-edge-colorable but not $(k-1)$-edge-colorable, then k is called the edge chromatic number of G, denoted $\chi'(G)$.

### Vizing's theorem

If G is a simple graph, then $\Delta(G) \leq \chi'(G) \leq \Delta(G) + 1$

If G is a bipartite graph, then $\chi'(G)=\Delta(G)$

When $n$ is odd ($n \neq 1$), $\chi'(K_n)=n$; when $n$ is even, $\chi'(K_n)=n-1$

### Constructive proof of Vizing's theorem for bipartite graphs

???+ note "Proof"
    Add edges in the bipartite graph in order.
    
    When we try to add the edge $(x,y)$, we try to find the smallest-numbered not-yet-used color for $x$ and $y$, say $l_x$ and $l_y$ respectively.
    
    If $l_x=l_y$, at this point we can directly set the color of this edge to $l_x$.
    
    Otherwise, suppose $l_x<l_y$; we can try to modify the color of the edge with color $l_x$ connected out from node $y$ to $l_y$.
    
    The modification process can be approximately regarded as a finite unique augmenting path starting from $y$, passing in turn through edges with colors $l_x,l_y,\cdots$.
    
    Because the augmenting path is finite, we can reverse the colors of all edges on the augmenting path, i.e. modify the ones originally colored $l_x$ to $l_y$, and modify the ones originally colored $l_y$ to $l_x$.
    
    According to the property of a bipartite graph, node $x$ cannot be a node of the augmenting path, otherwise it contradicts the smallest unused color being $l_x$.
    
    So after augmenting we can directly set the color of the edge connecting $x$ and $y$ to $l_x$.
    
    The total construction time complexity is $O(nm)$.

## Chromatic polynomial

$P(G,k)$ denotes the total number of different k-colorings of G.

$P(K_n, k) = k(k-1)\cdots(k-n+1)$

$P(N_n, k) = k^n$

In an undirected acyclic graph G,

1.  If $e=(v_i, v_j) \notin E(G)$, then $P(G, k) = P(G \cup e, k)+P(G\setminus e, k)$
2.  If $e=(v_i, v_j) \in E(G)$, then $P(G,k)=P(G-e,k)-P(G\setminus e,k)$

Theorem: let $V_1$ be a vertex cut set of G, and $G[V_1]$ is a complete subgraph of order $|V_1|$ of G, and $G-V_1$ has $p(p \geq 2)$ connected branches; then:

$P(G,k)=\frac{\Pi_{i=1}^{p}{(P(H_i, k))}}{P(G[V_1], k)^{p-1}}$

where $H_i=G[V_1 \cup V(G_i)]$

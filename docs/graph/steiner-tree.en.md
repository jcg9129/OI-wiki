The Steiner tree problem is a combinatorial optimization problem; similar to the minimum spanning tree, it is a kind of shortest network. The minimum spanning tree seeks the shortest network among the given point set and edges to make all points connected. While the minimum Steiner tree allows adding extra points outside the given points, so that the generated shortest network has the minimum cost.

## Problem introduction

In the early 19th century, Steiner, a famous scholar of geometry at the University of Berlin, studied a very simple but very enlightening problem: connect three villages with roads of extremely small total length. Mathematically speaking, it is to find, given three points $A$, $B$, $C$ in the plane, a fourth point $P$ in the plane such that the sum $a+b+c$ is shortest, where $a$, $b$, $c$ respectively denote the distances from $P$ to $A$, $B$, $C$.

The answer to the problem is: if each interior angle of triangle $\textit{ABC}$ is less than $120^{\circ}$, then $P$ is the point such that the angles subtended at this point by the edges $\textit{AB}$, $\textit{BC}$, $\textit{AC}$ are all $120^{\circ}$. If triangle $\textit{ABC}$ has an angle, for example angle $C$, greater than or equal to $120^{\circ}$, then point $P$ coincides with vertex $C$.

### Generalization of the problem

1.  In the Steiner problem, three fixed points $A,B,C$ are given. Naturally, we can generalize this problem to the case of given $n$ points $A_1,A_2,\dots,A_n$; we want to find a point $P$ in the plane such that the distance sum $a_1+a_2+\dots+a_n$ is extremely small, where $a_i$ is the distance $PA_i$.

2.  Considering other relevant factors of the points, the representation of weights is added. The other relevant factors of the $n$ points can be converted into a weight representation; find a point $P$ in the plane such that the total sum of the products of distance and weight $a_1\cdot w_1+a_2\cdot w_2+\dots+a_n\cdot w_n$ is extremely small, where $w_i$ is the weight of each point.

3.  Courant (R. Courant) and Robbins (H. Robbins) pointed out that the generalization of the first definition is superficial. In order to obtain a truly valuable generalization of the Steiner problem, we must give up looking for a single point $P$, and instead use a "road network" with the shortest total length. Mathematically expressed as: given $n$ points $A_1,A_2,\cdots,A_n$, find a connecting system of straight line segments that connects these $n$ points with the shortest total length, and any two points can be connected by a polyline composed of the straight line segments in the system. They called this new problem the **Steiner tree problem**. In the case of given $n$ points, there will be at most $n-2$ compound junction points (Steiner points). Through each Steiner point, at most three edges pass. If there are three edges, then they pairwise intersect at $120^{\circ}$ angles; if there are two edges, then this Steiner point must be one of the already-given points, and the angle at which these two edges intersect must be greater than or equal to $120^{\circ}$.

## Example problems

First, let us use a template problem to familiarize everyone with the minimum Steiner tree problem. See [[Template] Minimum Steiner tree](https://www.luogu.com.cn/problem/P6192).

The problem statement is already very clear: given $n$ points and $k$ key points in a connected graph $G$, connect the $k$ key points so that the sum of the weights of all edges of the spanning tree is minimized.

Combining the knowledge above, we can know that the sum of weights generated by directly connecting these $k$ key points is not necessarily the minimum, or these $k$ key points will not directly (adjacently) connect. So we should use the remaining $n-k$ points.

We use bitmask dynamic programming to solve it. We use $f(i,S)$ to denote a tree rooted at $i$, containing all points in the set $S$, with the minimum sum of edge weights.

Consider the state transition:

-   First, transfer over the connected subsets, $f(i,S)\leftarrow \min(f(i,S),f(i,T)+f(i,S-T))$.

-   Under the current subset-connected state, perform edge relax operations, $f(i,S)\leftarrow \min(f(i,S),f(j,S)+w(j,i))$. In the code below, a `tree[tot]` is used to record the relevant information of two connected nodes $i,j$.

Another classic example problem is [\[WC2008\] Tour plan](https://www.luogu.com.cn/problem/P4294).

This problem is to find the Steiner tree with the minimum sum of point weights; we use $f(i,S)$ to denote a tree rooted at $i$, containing all points in the set $S$, with the minimum sum of point weights. $a_i$ denotes the point weight.

Consider the state transition:

-   $f(i,S)\leftarrow \min(f(i,S),f(i,T)+f(i,S-T)-a_i)$. Because when merging here, the same point $a_i$ is added twice, so we subtract it.

-   $f(i,S)\leftarrow \min(f(i,S),f(j,S)+w(j,i))$.

We can find that the state transition is similar to the template problem above; what is troublesome is the output of the answer, and we also need to record the path during the DP process.

Use `pre[i][s]` to record the information of the point and set when transferring to the state rooted at $i$ with connected-state set $s$. After the DP ends, start from `pre[root][S]`, find those points connected to the points in the set and gradually decompose the set $S$, use the ans array to record those used points, and when the set is completely decomposed, the search ends.

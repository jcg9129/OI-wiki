A data structure is a way of storing and organizing data in a computer. From something as small as a variable or an array to something as large as a segment tree or a balanced tree, all are data structures.

The running of a program cannot do without data structures; different data structures each have their strengths and weaknesses and can handle different problems, and choosing a suitable data structure according to the specific problem can greatly improve a program's efficiency. So it is very necessary to learn all kinds of data structures.
